# Docs as Code

Практическая работа по настройке среды Docs as Code.

Автор: Челбаев М.

## Проект

EdgeCrafter-TOD — сервис детекции малых объектов (автомобили, суда, самолёты,
люди и т. д.) на аэро- и спутниковых снимках. Для обучения и оценки модели
используется датасет AI-TOD-v2.

## Запуск документации

```bash
uv sync
uv run mkdocs serve
```

После запуска сайт доступен по адресу <http://127.0.0.1:8000>.

## Загрузка датасета

```bash
uv run download-aitod
```

Для работы скрипта нужен токен Kaggle (`~/.kaggle/kaggle.json`).
