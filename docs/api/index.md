# API

API предоставляет доступ к функциям сервиса EdgeCrafter-TOD: загрузке
аэроснимков, детекции малых объектов и получению результатов.

## Основные операции

- `POST /detections` — загрузить снимок и найти на нём объекты;
- `GET /detections/{detectionId}` — получить сохранённый результат детекции;
- `GET /categories` — получить список классов объектов;
- `GET /models/current` — получить версию и параметры текущей модели.

## Пример ответа

```json
{
  "id": 1024,
  "status": "completed",
  "modelVersion": "yolos-tiny-aitod-1.2.0",
  "scoreThreshold": 0.5,
  "summary": { "vehicle": 37, "ship": 4 },
  "objects": [
    {
      "category": "vehicle",
      "confidence": 0.87,
      "bbox": { "x": 412.5, "y": 230.0, "width": 11.2, "height": 9.8 }
    }
  ]
}
```

## Очередь обработки

Если модель временно недоступна, `POST /detections` не возвращает ошибку:
снимок ставится в очередь, а сервис отвечает `202 Accepted`.

```json
{ "id": 1025, "status": "queued", "createdAt": "2026-11-05T10:20:00Z" }
```

Результат можно получить позже через `GET /detections/{detectionId}`:
пока статус `queued`, список объектов пуст, после обработки статус меняется
на `completed`.

## Ошибки

Все ошибки возвращаются в едином формате:

```json
{ "code": "INVALID_IMAGE", "message": "Uploaded file is not a valid image" }
```

| Код | Когда возникает |
|-----|-----------------|
| 202 | Модель временно недоступна, снимок поставлен в очередь (статус `queued`) |
| 400 | Файл не является изображением или порог вне диапазона 0–1 |
| 404 | Результат детекции не найден |
| 413 | Размер файла больше 50 МБ |
| 415 | Формат файла не PNG, JPEG или TIFF |
| 503 | Модель не загружена (`GET /models/current`) |
| 500 | Внутренняя ошибка сервиса |
