# Data Sheet

Исходная модель `hustvl/yolos-tiny` обучена на ImageNet-1k и COCO 2017
(118 тыс. изображений для обучения и 5 тыс. для валидации). Эти данные не содержат
аэроснимков, поэтому для проекта основным датасетом является **AI-TOD-v2** —
на нём модель дообучается и оценивается.

## Общая информация

**Название датасета:**
AI-TOD-v2 (Tiny Object Detection in Aerial Images, версия 2)

**Источник:**
Репозиторий авторов [Chasel-Tsui/mmdet-aitod](https://github.com/Chasel-Tsui/mmdet-aitod).
В проекте используется копия на Kaggle: `ngtininh/ai-tod-v2`.

**Назначение:**
Бенчмарк для обучения и оценки детекторов очень маленьких объектов на аэроснимках.

## Состав данных

**Объём:**
28 036 аэроснимков. Изображения те же, что в первой версии AI-TOD
(700 621 объект), а разметка переделана авторами во второй версии.

**Тип данных:**
Изображения 800×800 пикселей и разметка рамок объектов в формате COCO (JSON).

**Основные поля / признаки:**

- изображение (`file_name`, `width`, `height`);
- рамка объекта `bbox` — `[x, y, width, height]` в пикселях;
- класс объекта `category_id` — один из 8 классов: airplane, bridge, storage-tank,
  ship, swimming-pool, vehicle, person, wind-mill.

Средний размер объекта — около 12,8 пикселя, что намного меньше, чем в других
датасетах аэроснимков.

## Получение данных

Снимки взяты из нескольких открытых датасетов аэро- и спутниковой съёмки
(в том числе xView, DOTA и других) и нарезаны на фрагменты 800×800 пикселей.
Подробный состав источников приведён в статьях авторов.

## Предобработка

- исходные снимки нарезаны на фрагменты 800×800 пикселей;
- разметка приведена к единому набору из 8 классов и формату COCO;
- во второй версии разметка объектов была уточнена авторами.

Дополнительная очистка и фильтрация данных в источнике подробно не описаны.

## Ограничения

- часть изображений (из xView) не распространяется вместе с датасетом напрямую,
  и для полной сборки AI-TOD нужно отдельно скачивать xView;
- классы распределены неравномерно — транспортных средств намного больше, чем,
  например, мостов или ветрогенераторов;
- снимки собраны из разных источников с разным разрешением и условиями съёмки;
- география и время съёмки отдельно не указаны.

## Использование в проекте

AI-TOD-v2 используется для дообучения модели `hustvl/yolos-tiny` под классы
аэроснимков и для оценки качества детекции малых объектов. Классы датасета
совпадают с классами, которые возвращает endpoint `GET /categories`.
