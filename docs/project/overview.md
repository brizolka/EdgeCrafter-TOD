# EdgeCrafter-TOD — детекция малых объектов на аэроснимках

EdgeCrafter-TOD — сервис, который автоматически находит малые объекты
(автомобили, суда, самолёты, людей, резервуары и т. п.) на аэро- и спутниковых
снимках. Пользователь загружает снимок, сервис передаёт его ML-модели детекции
и возвращает список найденных объектов с координатами рамок, классом
и уверенностью модели.

Особенность задачи в том, что объекты на таких снимках очень маленькие:
средний размер объекта в датасете AI-TOD-v2 — около 12,8 пикселя. Поэтому сервис
ориентирован на модели, которые можно дообучить именно на малых объектах
и запускать на слабом оборудовании (edge-устройства, бортовые компьютеры БПЛА).

Основные пользователи:

- оператор мониторинга — загружает снимки и просматривает результаты;
- ML-инженер — отвечает за модель, её версию и качество работы.

Основные функции:

- загрузка аэроснимка на анализ;
- детекция объектов на снимке;
- просмотр результата: рамки объектов, классы и количество объектов каждого класса;
- просмотр списка поддерживаемых классов объектов.

## Комплект документации

1. **Описание проекта** — для всех участников и заказчика; объясняет назначение
   сервиса, пользователей и основные функции.
2. **Требования** — для аналитика, разработчиков и тестировщиков; фиксирует
   User Stories, Use Case и критерии приёмки.
3. **Архитектура системы** — для разработчиков и DevOps; описывает компоненты
   сервиса, их взаимодействие и диаграммы.
4. **Документация API** — для разработчиков клиентских приложений; описывает
   endpoints, форматы запросов, ответов и ошибок.
5. **Документация ML-модели** — для ML-инженеров и аудиторов; содержит Model Card,
   описание датасета, метрики, ограничения и риски.
6. **Руководство пользователя** — для операторов мониторинга; объясняет, как
   загрузить снимок и интерпретировать результат детекции.
7. **Руководство по развёртыванию** — для DevOps и инженеров edge-устройств;
   описывает установку сервиса и требования к оборудованию.
